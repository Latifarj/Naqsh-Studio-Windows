# راهنمای نسخهٔ دسکتاپ Windows نقش‌یار ۱.۲ آلفا

این شاخه (`technical-sheet-v1`) بستهٔ دسکتاپ Windows را ارائه می‌کند. پوشهٔ `web/` فقط رابط داخلی Electron است؛ نسخهٔ وب مستقل جزو این تحویل نیست. بستهٔ آلفا با شناسهٔ `com.naqshstudio.desktop.alpha` و پوشهٔ دادهٔ جدا از نسخه‌های قبلی نصب می‌شود.

## نصب و راه‌اندازی

۱. پس از اجرای workflow ویندوزی این شاخه، artifact با نام `Naqsh-Studio-technical-sheet-v1-Windows-x64` را دریافت کنید و ZIP آن را استخراج کنید.

۲. نصاب `.exe` را اجرا کنید، مسیر نصب را انتخاب و مراحل نصب را کامل کنید. این نصاب نسخهٔ ۱.۱ بتا یا ۱.۰ پیش‌نمایش را حذف یا به‌روزرسانی نمی‌کند.

۳. برنامه را از منوی Start یا میانبر «نقش‌یار ۱.۲ آلفا» باز کنید. backend محلی PDF همراه برنامه اجرا می‌شود و فقط روی `127.0.0.1` گوش می‌دهد؛ برای استفاده از نصاب به Python، حساب یا اینترنت نیاز نیست.

۴. برای ایجاد ورق، اندازهٔ شیت و قطعات را در میلی‌متر وارد کنید. قطعات استاندارد `Astin / آستین`، `tak / تک`، `Pan / پانچک` و `zih / زیح` کد و نام ثابت دارند. برای قطعهٔ دیگر «سفارشی» را انتخاب و کد انگلیسی معتبر و نام فارسی را وارد کنید.

۵. نقش را از کتابخانه انتخاب کنید، ناحیهٔ ماسک و تکرار را تنظیم کنید و اندازهٔ واقعی منبع/واحد تکرار را کالیبره و بازبینی کنید. برای نقش‌های raster، کنترل تولید حداقل ۳۰۰ PPI را الزام می‌کند؛ تصاویر با آستانهٔ ۱۲۸ به سیاه/سفید خالص تبدیل می‌شوند. SVGهای برداری به‌صورت برداری باقی می‌مانند.

۶. از خروجی **PDF فنی سیاه‌وسفید** استفاده کنید. ابتدا **PDF خط‌کش تست مقیاس ۱۰۰٪** را چاپ و خط ۱۰۰ میلی‌متری را اندازه بگیرید؛ در پنجرهٔ چاپگر Fit to page را خاموش کنید. برای شابلون، چاپگر و کاغذ را روی اندازهٔ واقعی تنظیم و نتیجه را روی یک نمونه بازبینی کنید.

## ساخت اولین ورق، مرحله‌به‌مرحله

۱. نام پروژه، نام مشتری و شمارهٔ سفارش را وارد کنید. عرض و ارتفاع شیت را مطابق کاغذ یا رول چاپگر تنظیم کنید. واحد نمایش میلی‌متر یا سانتی‌متر است؛ محاسبات و ذخیرهٔ داخلی همیشه میلی‌متری‌اند.

۲. «افزودن» را در بخش قطعات بزنید، نوع قطعه را انتخاب و عرض، ارتفاع و تعداد را وارد کنید. برای سینه، کنار، سرشانه یا حاشیه، نوع «سفارشی»، یک کد لاتین مانند `Sineh` و نام فارسی بدهید. اندازه‌های نمونهٔ نمایشی فرضی‌اند.

۳. حالت جانمایی پیش‌فرض «خودکار» است. برای موقعیت مستقل، حالت «دستی» و مختصات X/Y روی شیت را بدهید؛ مبدأ گوشهٔ بالا-چپ ورق است. قطعهٔ دستی باید تعداد ۱ داشته باشد؛ برای چند نسخه با موقعیت دلخواه، قطعه را کپی کنید. مختصات بیرون ورق یا همپوشانی مستطیل محیطی قطعه‌ها خطا می‌دهد. چرخش ۹۰ درجه و قرینهٔ قطعه جداگانه قابل تنظیم‌اند. فاصلهٔ مناسب برای برچسب بالای هر قطعه را هم در پیش‌نمایش کنترل کنید.

۴. یک لایهٔ نقش اضافه و کد را در کتابخانه جست‌وجو کنید، یا PNG/JPEG/SVG وارد کنید. ردیف بدون کد در تکرار نادیده گرفته می‌شود. اندازهٔ واقعی نقش را کالیبره کنید؛ پیش از تأیید تطبیق کد و تصویر، صفحهٔ مرجع را بررسی کنید. تأیید تطبیق به معنی بی‌درزبودن مرز تکرار نیست.

۵. در «ویژگی‌ها» روش تکرار افقی، عمودی یا شبکه‌ای، اندازهٔ واحد، فاصلهٔ X/Y، جابه‌جایی فاز، چرخش و قرینه را تنظیم کنید. تکرار از مرکز ناحیه محاسبه می‌شود. هر لایه را می‌توان اضافه، حذف یا غیرفعال کرد؛ ناحیهٔ ماسک مانع بیرون‌زدن نقش از قطعه می‌شود.

۶. تغییرات خودکار ذخیره می‌شوند. از «مدیریت پروژه‌ها» پروژه را باز، کپی یا از تاریخچه بازیابی کنید. پس از تکمیل سفارش، حتماً یک **JSON تبادل خودبسنده** نیز در پوشهٔ پشتیبان مستقل ذخیره کنید؛ ذخیرهٔ خودکار جای پشتیبان جدا را نمی‌گیرد.

۷. «کنترل تولید» را بررسی و موارد بحرانی را اصلاح کنید. PDF فنی را بگیرید، اندازهٔ صفحه را در نرم‌افزار PDF بررسی کنید و با **Actual size / 100%** چاپ کنید؛ Fit، Shrink و Scale to fit را خاموش کنید. ابتدا خط ۱۰۰ میلی‌متری را اندازه بگیرید. آزمون نرم‌افزاری جای تست چاپ فیزیکی را نمی‌گیرد.

نصاب امضای تجاری ندارد. در صورت هشدار Windows، منبع فایل و SHA-256 همراه آن را بررسی کنید؛ حفاظت Windows را غیرفعال نکنید. در PowerShell دستور `Get-FileHash .\Naqsh-Studio-1.2.0-alpha.1-x64.exe -Algorithm SHA256` باید با فایل `.sha256` یکسان باشد.

## پروژه‌ها و انتقال از نسخه‌های قبل

- دادهٔ این نسخه در `%APPDATA%\Naqsh Studio 1.2 Alpha\projects` ذخیره می‌شود و تا پنج نسخهٔ قبلی پروژه را نگه می‌دارد. نسخه‌های قدیمی مسیرهای دادهٔ خود را دارند؛ انتقال خودکار صورت نمی‌گیرد.
- در نسخهٔ قبلی از **JSON تبادل خودبسنده** خروجی بگیرید و آن را در نسخهٔ آلفا وارد کنید. این فایل برای نقش‌های استفاده‌شده دارایی‌ها را همراه دارد.
- ذخیره‌سازی، تاریخچه و PDF در دستگاه محلی باقی می‌مانند؛ همگام‌سازی ابری/حساب کاربری در برنامه وجود ندارد.

## اجرای توسعه و ساخت نصاب

برای اجرای توسعه روی Windows (Node.js 20+ و Python 3.10+):

```powershell
py -3 -m pip install -r requirements.txt
npm ci
npm run desktop
```

برای ساخت نصاب x64 روی Windows، MSYS2 را نصب کنید، بستهٔ `mingw-w64-x86_64-cairo` را اضافه و مسیر DLLهای Cairo را تنظیم کنید:

```powershell
$env:CAIRO_DLL_DIR = 'C:\msys64\mingw64\bin'
py -3 -m pip install -r requirements-desktop.txt
npm ci
npm run dist:win
```

خروجی در `release/win/` قرار می‌گیرد. workflow `.github/workflows/build-windows.yml` همین آزمون‌ها و ساخت را روی `windows-2022` اجرا می‌کند و artifact نگه می‌دارد. این محیط توسعه Linux است و نصاب Windows در آن ساخته/اجرا نشده؛ workflow باید روی Windows تکمیل شود و نصب واقعی همچنان نیازمند آزمون Windows است. نصاب unsigned است و Windows ممکن است هشدار ناشر ناشناس نشان دهد.

## معماری و محدودیت چاپ

- `shared/engine.js` مدل هندسه، قطعات، برچسب‌های دوزبانه، تکرار و SVG را نگه می‌دارد؛ `web/app.js` فقط رابط Electron است. این جداسازی موتور را برای نگهداری/توسعهٔ آتی قابل استفاده می‌کند، اما وب محصول این تحویل نیست.
- `server.py` تنها مسیر تولید PDF را کنترل می‌کند: پروفایل `technical-bw-v1`، ابعاد فیزیکی مورد انتظار، حداقل PPI و تبدیل قطعی raster. متن دوزبانه با وزیرمتن و شکل‌دهی RTL به تصویر یک‌بیتی ۶۰۰ DPI تبدیل می‌شود؛ خطوط هندسی و نگاره‌های برداری بدون متن برداری می‌مانند. برای خروجی قطعی، SVGهای دارای gradient، pattern یا mask رد می‌شوند و باید پیش از ورود به برنامه تخت شوند. پس از تولید، رنگ عناصر برداری و پیکسل‌های تصویر PDF دوباره بررسی می‌شوند.
- متنِ توکار در SVG نقش نیز باید به مسیر تبدیل یا تصویر تخت شود؛ این محدودیت از جداشدن حروف فارسی در موتورهای SVG جلوگیری می‌کند. برچسب‌های خود برنامه از مسیر شکل‌دهی ۶۰۰ DPI استفاده می‌کنند.
- PDF برداری، مشکی خالص روی سفید خالص است؛ raster با ترکیب شفافیت روی سفید و آستانهٔ ثابت ۱۲۸ به سیاه یا سفید می‌رود. وضوح ۳۰۰ PPI حداقل چاپ و ۶۰۰ PPI کیفیت ترجیحی است.
- برچسب‌ها افقی و بیرون قطعه می‌مانند؛ برای بریده‌نشدن آن‌ها دست‌کم ۹ میلی‌متر حاشیهٔ بالایی لازم است. اگر متن از صفحه بیرون بزند، preflight یا PDF export متوقف می‌شود.
- این ابزار هنوز CMYK، رنگ مشکی تک‌کاناله، bleed، PDF/X، Nesting صنعتی چندشیتی یا تأیید چاپخانه را فراهم نمی‌کند. اندازه‌های فرضی نمونه را برای تولید واقعی استفاده نکنید.
- در پوستهٔ Electron، `nodeIntegration` خاموش، `contextIsolation` و sandbox روشن است؛ سرور فقط به loopback متصل است و دانلود از پنجرهٔ ذخیرهٔ بومی استفاده می‌کند.
